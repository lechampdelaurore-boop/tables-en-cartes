# Tables en cartes

Flashcards pour apprendre les tables de multiplication de 2 à 10.

- **Jouer en ligne :** https://lechampdelaurore-boop.github.io/tables-en-cartes/
- **Cartes à imprimer :** [cartes-multiplication-a-imprimer.pdf](cartes-multiplication-a-imprimer.pdf) (A4 recto-verso, bord long, échelle 100 %, 81 cartes)

## Le jeu

- Choix des tables de 2 à 10, avec une barre de progression par table.
- Deux modes : cartes à retourner, ou réponse à taper.
- Les cartes ratées reviennent quelques cartes plus tard.
- Astuces de calcul au dos des cartes (×9, ×5, ×4…).
- Défi chrono : 1 minute pour trouver un maximum de réponses, avec record.
- Les progrès sont gardés dans le navigateur (aucun compte, aucune donnée envoyée).

Une seule page HTML, sans dépendance, à ouvrir directement dans un navigateur.
